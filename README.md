## Project Description

This project is an advanced Android mobile application developed using Kotlin and Jetpack Compose. It extends the previous project by adding more screens and advanced mobile features, including local data persistence, cloud integration, web API usage, and mobile hardware sensor integration.

The application is designed based on the selected Sustainable Development Goal (SDG) theme and aims to provide a useful, interactive, and practical mobile solution.

## SDG Theme

This project continues SDG 3: Good Health and Well-being from Project 1.

## Main Features

* Minimum 7 screens using Jetpack Compose Navigation
* Local data persistence using Room Database
* Cloud data storage using Firebase Firestore
* Internet data fetching using REST API / Retrofit
* Sensor integration such as camera, location, or device sensor
* ViewModel state management
* Modern Material Design user interface

## Technologies Used

* Kotlin
* Jetpack Compose
* Android Studio
* Room Database
* Firebase Firestore
* Retrofit / REST API
* ViewModel
* Navigation Compose
* Material 3

## Setup Instructions

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Sync the Gradle files.
4. Connect an Android emulator or physical Android device.
5. Run the application.
6. Make sure internet permission and Firebase configuration are correctly set before testing API and cloud features.
