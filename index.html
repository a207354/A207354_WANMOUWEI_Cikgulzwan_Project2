SDG Theme

SDG Theme & Learning Goal

My selected theme is SDG 3: Good Health and Well-being, because mobile technology can support users in tracking emotions, building healthier habits, and improving personal awareness. Through this course, my goal was to improve my Android development skills and understand how real mobile applications combine UI design, state management, local storage, internet data, cloud services, and sensor features.

Lab Submissions

Lab 1 to Lab 5 show my progress from basic UI construction to persistent data storage.

Lab 1UI

Lab 1: Basic User Interface

This lab focused on building a simple mobile interface using Compose layout components.

I learned how to arrange UI elements clearly using basic layout structures. This lab helped me understand how visual hierarchy and spacing affect the user experience.

Lab 2Interaction

Lab 2: Interaction

This lab introduced interactive components such as clickable items, input fields, and user actions.

I learned how to make an interface respond to user input. It helped me understand that a mobile app should not only look good, but also provide clear feedback to the user.

Lab 3Material Design

Lab 3: Material Design

This lab focused on applying Material Design principles, theming, and improved visual styling.

I learned how typography, colours, cards, and shapes improve the professional look of an app. This lab also helped me become more confident in creating consistent UI design.

Lab 4Navigation

Lab 4: Navigation

This lab introduced multiple screens and navigation flow using Navigation Compose.

I learned how to connect screens and pass users through a more complete app flow. This was important preparation for Project 1 because real applications normally need more than one screen.

Lab 5Room

Lab 5: Room Database

This lab focused on local data persistence using Room Database.

I learned how to save data permanently on the device and display saved data later. This helped me understand why persistence is important for useful mobile applications.

Project 1: MoodFlow

Reflection & Learning Journey

From Lab 1 to Project 2, I gradually developed my ability to build Android applications using Kotlin and Jetpack Compose. At the beginning, I mainly focused on basic layout and UI structure. Later, I learned how to add interaction, navigation, ViewModel state management, Room Database, API integration, Firebase, and sensor features. The biggest challenge was understanding how different technical parts connect together, especially persistence, cloud data, and live API data. This project helped me see how mobile applications can support real user needs and connect with the SDG theme through practical digital solutions.
